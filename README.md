# stitchlist

Stitch HTML/Markdown list fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/stitchlist/

## Install / run

```bash
git clone https://github.com/theworker02/stitchlist.git
cd stitchlist
node src/cli.js
node --test
```
